>_SORPHLITE

A free multi-engine sample player / granular synth.

Free · VST3

Windows Windows 10+ · 64-bit Download for Windows
  1. Run the installer. If Windows shows “Windows protected your PC”, click More info → Run anyway.
  2. It installs to C:\Program Files\Common Files\VST3.
  3. Rescan plugins in your DAW.
macOS macOS 11+ · Apple Silicon & Intel Download for macOS
  1. Open the .dmg.
  2. Drag SorphLite.vst3 onto the VST3 Plug-Ins folder and enter your password.
  3. Rescan plugins in your DAW.
