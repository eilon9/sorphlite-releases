# SorphSampler

A free multi-engine sample player / granular synth — VST3 for Windows and macOS.

**Download the latest version from the [Releases page](../../releases/latest).**

- **Windows:** run `SorphSampler-<version>-Windows-Setup.exe`. It installs the VST3 into `C:\Program Files\Common Files\VST3`.
- **macOS:** open `SorphSampler-<version>-macOS.dmg` and drag `SorphSampler.vst3` onto the *VST3 Plug-Ins* shortcut.

Then rescan plugins in your DAW.

SorphSampler is freeware: free to use, closed source. See [EULA.txt](EULA.txt).
